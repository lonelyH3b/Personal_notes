# 📚 Knowledge Base

A collection of technical notes, debugging experiences, and concepts I learn while building software.

![](media\banner.png)

This repository is my personal knowledge base, maintained in public so that others can benefit from the same lessons.

Many of these notes begin with a real problem I encountered while building a project. Instead of only recording the solution, I document:

- What happened
- Why it happened
- How I investigated it
- Why the solution works

My goal is to build understanding rather than just a collection of fixes.

## Philosophy

I don't want this repository to become a list of copied commands.

Instead, each note should answer questions like:

* Why does this work?
* Why did it fail?
* What assumption was incorrect?
* How can I reason about similar problems in the future?

If a future version of myself forgets a concept, I should be able to read one of these notes and understand it again without searching the internet.

---

## Learning in Public

These notes are public because someone else may encounter the same problem tomorrow.

If even one note saves another developer an hour of debugging, then documenting it was worthwhile.
