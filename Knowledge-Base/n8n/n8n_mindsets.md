# n8n Workflow Mindset

While working with n8n, I'm trying to develop a simple habit:

> **Don't add a node just because I can. Add it because I need it.**

### 1. Keep the workflow simple

A workflow doesn't become better just because it has more nodes.

Before adding complexity, I should ask whether the problem actually requires it.

### 2. Ask: "Why am I adding this node?"

Every node should have a clear purpose.

If I can't explain:

* what the node does,
* why I need it, and
* what would happen without it,

then I should reconsider adding it.

### 3. Brainstorm before building

Before opening n8n, sketch the workflow logic first.

Digital pad if available.

Paper + pencil if not.

Apparently, I'm either too poor to buy another productivity gadget, or my hand simply doesn't itch to spend money. 😂

### The principle

**Think → simplify → build → test → remove unnecessary complexity.**

I'm realizing that automation isn't necessarily about building the biggest or most sophisticated workflow.

Sometimes good automation means finding the **fewest steps needed to reliably solve the problem**.
